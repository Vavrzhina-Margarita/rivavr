# Film-Inspired Photo Editor

A web-based photo editor that gives digital photos a film-inspired look.

Adjust the visual character of your images to evoke the atmosphere of analog photography, with a focus on color, mood, and texture.

## Features

- Apply a film-inspired aesthetic to digital photos
- Explore visual treatments inspired by analog photography
- Preview and refine your images in the browser

## Built With

- HTML
- CSS
- JavaScript
